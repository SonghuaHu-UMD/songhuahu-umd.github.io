GoatCounter never stores the address, by design, so this cannot be repaired after the fact: the reader's own browser is the last place the province is still known. So mainland-looking readers resolve their own region once per session against ipwho.is and report it back as an event. ipwho.is answers "ZJ" for Zhejiang -- already the ISO 3166-2 code that scripts/build-visitor-map.js knows how to place -- and it sends Access-Control-Allow-Origin, so this stays a plain fetch() and no third-party script ever runs in this page. Deliberate limits: - Mainland time zones only. Everyone else is already placed correctly by GeoLite2, so no one else's address is sent anywhere. - One lookup per session, cached in sessionStorage. The event still fires on every pageview, so its counts stay comparable to the pageview counts they are subtracted from. - Every failure is silent -- blocked, offline, timed out, private-mode storage. The reader ends up exactly where they were before this existed: counted, in China, with no province.
